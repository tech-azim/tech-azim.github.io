01 / The Journey

Engineering with empathy for the end user.

I'm a product engineer with a strong visual sensibility. My career began at the intersection of graphic design and programming — I quickly realized that the biggest bottleneck in building software is often the communication gap between design mockups and frontend architecture.

Over the last five years, I have worked across fast-moving startups and high-stakes enterprise projects in Southeast Asia. I served as frontend developer for IFG Life, Indonesia’s state-owned insurance holding platform, modernizing policies for millions of users. I engineered the enterprise portal for Malaysia’s Registrar of Societies (eROSES JPPM), and designed and built Dimedika EHR, an intuitive medical records workflow for solo practitioners.

My guiding philosophy is simple: Every microsecond and every pixel counts. When an interface is responsive, accessible, and fast, users build confidence in the product.

02 / Working Principles

How I approach software engineering.

01

Performance as a Foundation

Speed isn't an afterthought. Sub-second initial loads, 60fps interaction budgets, zero cumulative layout shifts (CLS), and lean bundles are treated as core acceptance criteria.

02

Tokens & Living Systems

Bridging Figma variables directly to Tailwind config and CSS tokens. Atomic, headless components that guarantee accessible keyboard navigation and unified brand expression.

03

Clean Domain Architecture

Decoupling UI layers from data services. Strong TypeScript types, runtime Zod validation, and microfrontend isolation so large teams can ship concurrently without collisions.

04

Pragmatic Product Thinking

Code exists to serve users and businesses. I prioritize feature velocity and maintainability over over-engineering, while never compromising on user delight.
